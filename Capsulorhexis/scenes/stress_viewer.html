What this shows · 這是什麼

This is the capsule membrane's stress field, drawn on its undeformed (flat) reference shape. It does NOT deform — think of it as a fixed map: each triangle sits where that patch of membrane starts, and its colour tells you how hard that patch is being stressed right now in the live SOFA simulation.

這是囊膜的應力場,畫在它的未變形(平坦)參考形狀上。它不會變形 —— 把它想成一張固定的地圖:每個三角形待在那塊膜「起始」的位置,顏色告訴你那塊膜 此刻在 SOFA 模擬裡受多大應力。變形在 SOFA 視窗看,受力集中在哪在這裡看。

Where the numbers come from · 數值哪裡來

The value is per triangle (per element), not per node — one colour per triangle. It is not read out of SOFA's FEM (SOFA computes stress in C++ but does not expose it to Python). Instead our own numpy code (principal_stress()) re-derives it from geometry: rest vs current triangle → deformation gradient F → Green strain ε = ½(FᵀF−I) → plane stress σ = C·ε → its largest principal value σ₁ and direction. In FEM mode with matched E/ν this equals SOFA's own FEM stress at small strain; in mass-spring mode there is no continuum E, so σ₁ is a geometric-strain scale (the pattern of where it is high is the same either way).

逐「三角形」(element),不是節點 —— 每個三角形一個顏色。它不是 SOFA FEM 吐出來的(SOFA 在 C++ 內部有算應力,但沒開放給 Python),而是我們自己的 numpy (principal_stress())用幾何重算:靜止 vs 當前三角形 → 形變梯度 F → Green 應變 ε = ½(FᵀF−I) → 平面應力 σ = C·ε → 取最大主值 σ₁ 與方向。FEM 模式且 E/ν 對齊時,小應變下等於 SOFA FEM 的應力;mass-spring 模式沒有真 E,σ₁ 是幾何比例尺(但「哪裡最緊」的分佈一樣)。

Colour = σ₁ (max principal stress) · 顏色 = σ₁(最大主應力)

σ₁ is the largest in-plane tension in that triangle. blue = relaxed … red = peak. The scale (bottom-left) auto-fits the current peak; Scale switches to a fixed ceiling. Grey = a degenerate triangle (collapsed/inverted) where σ₁ is not physical.

σ₁ = 該三角形內最大的面內張應力。 藍 = 鬆弛 … 紅 = 峰值。色階(左下)自動 對到目前峰值;按 Scale 切成固定上限。灰色 = 退化三角形(塌陷/翻面),σ₁ 不可信。

Hover a triangle · 滑鼠移到三角形上

Shows σ₁, radius r, area ratio, the σ₁ direction, and the crack class. A crack would run perpendicular to σ₁ (Rankine). Comparing that to the radial direction:

  • CIRCUMFERENTIAL — the good, curvilinear tear (stays a circle). 圓周向,好的圓弧撕。
  • RADIAL — the dangerous one that runs out to the periphery. 徑向,危險(裂到周邊)。
  • oblique — in between. 斜向,介於之間。

顯示 σ₁、半徑 r、面積比、σ₁ 方向、以及裂向分類。裂縫會垂直於 σ₁ (Rankine);拿它跟徑向比:上面三類。被指的三角形會畫出白線=σ₁ 方向、紅虛線=裂縫方向。

Timeline — drag freely, review after · 時間軸 — 先拉,事後回看

You don't have to watch while you drag. Every frame is recorded. The bar at the bottom is ◉ LIVE by default (follows the newest frame). Drag the slider or press ▶ to scrub back through history and hover any past moment; Space or ◉ returns to live.

不用邊拉邊看。每一幀都錄下來。底部預設 ◉ LIVE(跟著最新)。 拖拉桿或按 ▶ 回放歷史、滑到任一過去時刻查數值;Space 或 ◉ 回到即時。
