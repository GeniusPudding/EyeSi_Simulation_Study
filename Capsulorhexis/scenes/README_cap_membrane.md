# Demo:圓形薄膜(球冠)貼合在圓球上,拉力超過門檻才剝離

`cap_membrane.py` 是 `paper_gel_tear.py`(平面版)的**圓形版**:一張**圓形薄膜**做成
**淺球冠(spherical cap)**、貼合在一顆**圓球(lens)**上,用**完全相同的物理**——
每條邊硬度(不亂伸縮)、對球體的**有門檻黏著**、黏滯阻尼、以及**塑性 freeze**(拉完
定型不彈回)。這是往 capsulorhexis(前囊撕開)幾何靠近的第一步。

## 執行

```powershell
.\Capsulorhexis\scenes\run_cap.ps1
# 缺 cap.obj 會自動用 generate_cap.py 產生;再 runSofa -g imgui -a cap_membrane.py
```

## 幾何(generate_cap.py 一次產生兩個檔)

底座**不是整顆球,而是扁的橢圓球(oblate ellipsoid,像水晶體)**,以原點為中心:

```
x²/A² + y²/A² + z²/C² = 1      A=7(橫向)、C=1.75(縱向)→ 扁度 C/A = 0.25
```

- `lens.obj` — 扁橢圓底座(細緻切分 9216 三角形)。**弧度已減半**(C:3.5 → 1.75)。
- `cap.obj` — 圓形薄膜(865 頂點、1656 三角形),**覆蓋整個上半橢球**:
  `CAP_ANGLE_DEG = 90` → 冠緣正好落在**赤道**(半徑 R=A=7、z=0),冠頂高 = C = 1.75。

**薄膜用「極角 v」分環,不是用平面半徑**:
```
P(v,u) = ( A·sin v·cos u , A·sin v·sin u , C·cos v )     v: 0(極點) → 90°(赤道)
```
這很重要——赤道附近曲面幾乎垂直,若照平面半徑等分會產生嚴重拉長的三角形。

- 想更扁/更拱:調 `C`;想改覆蓋範圍:調 `CAP_ANGLE_DEG`(90=整個上半;60=只蓋中央)。

**兩個網格由同一條解析曲面產生 → 薄膜完全貼合底座、不會浮空。**
(先前用 SOFA 內建 `sphere.obj` 只有 382 頂點,面片會凹進真實球面內,薄膜看起來就
「沒有完全貼在上面」——這就是原因,已修掉。)

- 想更扁:`C` 調小;想更大/更小:`A`、`R`;弧度由 `A`、`C` 一起決定。
- 薄膜**不是靠接觸**貼著,而是靠**黏著吸力**(見下)——原本吸住、被拉起才浮起來。

## 物理(與平面版相同,細節見 `README_paper_gel_tear.md`)

- **黏著到球** = `RestShapeSpringsForceField`(把每個節點拉回它在球上的原位);
- **門檻剝離** = controller:黏著力 `ADHESION_STIFF×抬起距離 > BREAK_FORCE` 就斷開;
- **不亂伸縮** = `MeshSpringForceField`(每條邊)+ `TriangularBendingSprings`;
- **拉完定型不彈回** = freeze(`rest←current` + reinit 彈簧 + **清掉黏著**),自動於
  `FREEZE_T` 或按 `F` 手動;
- CG 30 迭代 → 實測 ~600 FPS(暫停)、動態順暢。

## 操作(預設:打開後薄膜「吸住不動」,你不拉它就不會浮)

| 動作 | 做法 |
|---|---|
| 拉薄膜 | **Shift + 左鍵拖曳**。輕拉→吸住不動;拉力超過 `BREAK_FORCE`→該處吸力斷開、浮起剝離 |
| 定型 | **自動的,不用按鍵**(見下「自動塑性」)。`F` 只是「整片立刻凍結」的快捷鍵 |
| 轉視角 | 左鍵拖曳(不按 Shift);滾輪縮放 |

## Shift+左鍵拖曳:SOFA 到底是怎麼決定「拉哪一點」的

1. **射線**:從**相機**穿過**滑鼠像素**射出一條 ray。
2. **只打得到碰撞模型**:ray 與場景中的碰撞模型求交 —— 只有薄膜有
   `TriangleCollisionModel`。**水晶體沒有碰撞模型(純視覺)**,所以永遠抓不到它。
3. **取離相機最近的交點**:命中的是**三角形上的一點**(重心座標),不是頂點;
   `BaseContactMapper` 在該三角形上建對應點。
4. **接彈簧**:`AttachBodyPerformer` 在該點與一顆「**滑鼠虛擬質點**」之間建一條
   `SpringForceField`,勁度 = `AttachBodyButtonSetting.stiffness`(`MOUSE_STIFFNESS`)。
5. **拖曳**:滑鼠質點只在「**平行螢幕、通過命中深度**」的平面上移動 →
   **你只能在螢幕平面內拉**,沒辦法往螢幕深處/外拉。
6. **放開**:performer 移除、彈簧消失;再按就重新射線、重新命中、重新建彈簧。

### ⚠️ 為什麼會「亂跑」——掠射角(grazing angle)

相機**仰角太低**時,ray 幾乎**貼著**這個又扁又寬的薄膜表面射過去 →
**滑鼠移 1 像素,命中點會在薄膜上滑好幾 mm**,而且會在三角形間跳。
所以相機角度**不只影響好不好看,更決定抓取準不準**。現在相機設在
`[10,-10,11]`(仰角約 38°),ray 比較垂直打在薄膜上 → 抓取穩定。
**若又覺得抓不準,先把視角轉陡一點再抓。**

另外:薄膜**翻摺後有兩層**,ray 一律取**離相機最近**那層 —— 可能抓到翻上來的那片。

`arrowSize=0.3` 會把那條彈簧畫出來,**可以直接看到抓在哪一點**。

## 自動塑性(不用按 F 就「不太彈回」)

純彈性一放手就彈回;真實組織不會。所以**已經剝離的部分**會慢慢把「當前形狀」變成
自己的 rest 形狀(viscoplastic creep):你拖的時候 rest 一直追上來,放手時幾乎沒有
彈性能可彈回 → **自動停在原地**。還黏在水晶體上的節點 rest 不變,黏著照樣把它們吸住。

- `PLASTIC_RATE = 0.25`(0=完全彈性會彈回,1=像油灰立刻定型)、`PLASTIC_EVERY = 5` 步。
- 實測:t=6 放手(不按 F、不 freeze)→ maxZ 3.231 → t=15.5 仍 3.284,**不彈回**。

## 薄膜不會再穿透水晶體

水晶體現在是**實體障礙**:`EllipsoidForceField`(解析橢圓球斥力,便宜又穩,不需網格碰撞),
把任何陷進去的節點推回表面 → 薄膜是**往上翻摺**,不會往下穿透。
`LENS_REPULSION = 800`(**正值 = 向外推**;SOFA 慣例見 `EllipsoidForceField.h`:
positive to repulse outward)。實測:穿透節點數 = **0**。

## 想讓薄膜「容易翻摺、攤回原本薄膜上方」而不是硬直立在空中

### ⚠️ 先講一個本質矛盾
**「自動不彈回(塑性)」和「自己軟趴趴倒下去」是互相矛盾的。** 塑性的定義就是
「**維持你留下的形狀**」—— 所以它才會杵在空中。真實 capsulorhexis 的瓣片也不是靠
重力倒下,是**醫師把它拖過去**的。所以:

> **要翻摺,就用滑鼠把瓣片「橫向拖過去」(拖到薄膜上方),不是只往上拉。**
> 拖過去之後,塑性會幫你**保持翻摺的姿勢**。

### 可調的參數(依影響力排序)

### 怎麼把它翻面攤平(實測可行)

拖曳方向**大致平行原本薄膜**(往上提一點,然後**橫向掃過去**)→ 瓣片會**逐漸翻面攤過來**。
實測(腳本模擬「提起 → 橫掃到對側」):瓣片翻過去後**停在薄膜上方**,
陷入下層深度僅 **0.05mm**(可忽略),無 NaN。

💡 **技巧**:滑鼠只能在「**平行螢幕**」的平面拖(見上一節)。所以想「平平地把它拖翻過來」,
就把**視角轉成接近俯視** —— 這時螢幕平面 ≈ 薄膜平面,拖曳方向自然就跟薄膜平行了。

### 可調的參數(依影響力排序)

| 參數 | 效果 |
|---|---|
| **`BEND_STIFFNESS`**(現 **40**)| **最主要**。小=軟趴、容易翻摺攤平;大=硬挺、立在空中撐成大圓弧。<br>⚠️ 歷史:原本 200 →(誤讀「軟一點」而**調錯方向**)600 → 修正為 120 → **40** |
| **`PLASTIC_RATE`**(現 **0.12**)| 定型速度。太大(0.25+)→ 拖到一半就「硬掉」不好再摺;小 → 保持可塑,但放手後回彈稍多 |
| **`SELF_COLLISION = True`** | 翻過去的瓣片會**躺在**下面的薄膜上,而不是穿過去(**SOFA 預設 False**)|
| `DAMPING`(現 2.0)| 小 → 反應更靈活好拖;大 → 黏滯遲鈍 |
| `MOUSE_STIFFNESS`(現 1000)| 大 → 拖得動、不易滑脫 |

### ⚠️ 自體碰撞的 proximity 一定要小於網格邊長

`MinProximityIntersection` 的 `ALARM_DISTANCE` **必須明顯小於網格邊長**
(這裡邊長 ≈ `2πA/M` = **0.611**)。原本設 0.5 太接近 → **相鄰三角形互相誤判成碰撞**,
薄膜自己推自己(抖動 + 白做工)。收到 **0.25 / contactDistance 0.12** 後:
**速度從 184 → 374 步/秒(快一倍)**,靜止仍完全吸住、無 NaN。

另註:目前擋住「穿到下層薄膜」的**主力其實是 `EllipsoidForceField`**(水晶體實體障礙),
因為下層薄膜本來就貼在水晶體上。自體碰撞主要負責**瓣片對摺到自己身上**的情況。

### ❌ 重力不是這裡的旋鈕(實測結論)

我實測過用重力讓它自己倒下,**行不通**:

| `GRAVITY_Z` | 結果 |
|---|---|
| −2 / −10 | 完全推不動(塑性定型後的勁度贏過重力)|
| **−40** | **整片被扯離水晶體**:glued 865→**1**、meanZ −4.69(整個掉走)|
| −120 | 混亂,仍不翻摺 |

因為**重力和 `BREAK_FORCE` 吃同一份力預算**:弱到安全就推不動,強到推得動就把整片
membrane 從水晶體上扯下來。所以 `GRAVITY_Z = 0`。

## 摺痕弧度 → 調 `BEND_STIFFNESS`

摺痕的**尖銳程度**由 `TriangularBendingSprings.stiffness`(`BEND_STIFFNESS`)決定:

| 調整 | 效果 |
|---|---|
| **調大**(現在 600,原本 200)| 更抗彎 → 摺痕**平緩、圓弧、不會死摺** |
| 調小 | 更軟趴 → 摺痕**更尖、捲得更緊**(就是你說的「太彎」)|

⚠️ 注意「軟」有兩種,別調錯:
- **面內軟硬**(會不會被拉長)= `PAPER_YOUNG` / `EDGE_STIFFNESS`;
- **摺痕尖不尖**(翻摺弧度)= `BEND_STIFFNESS`。
「翻摺太彎」要**調大** `BEND_STIFFNESS`(已先幫你 200→600);還太彎就再往上加。

- **`SCRIPTED_PULL = False`(預設)**:一打開**什麼都不會動**,薄膜就吸在扁球上。
  (設成 `True` 會在 t=1s 自動抬 +x 冠緣示範剝離——但 GUI 跑到數百 FPS,看起來就像
  「一打開薄膜自己浮起來」,那不是物理,是腳本。)
- **`MOUSE_STIFFNESS = 1000`**:GUI 內建的滑鼠彈簧太弱,拉不動黏著(這就是先前
  「有黏著但拉不動」的原因)。這個值要**明顯大於** `BREAK_FORCE`,才拉得起來;
  想更好拉就再調大,或把 `BREAK_FORCE` 調小。

## 下一步(你提到的「沖入玻璃體壓扁圓球、薄膜跟著貼」)

目前球是**靜態視覺**。要做「壓扁球、薄膜跟著」有兩條路:
1. **動畫化球體**:把球半徑/形狀隨時間壓扁,並讓薄膜的**黏著目標(rest)跟著球面更新**
   → 薄膜就會貼著被壓扁的球變形(需要一個會動的 base MO 給黏著當外部參考)。
2. **可變形球體**:球做成實體(tet)FEM,外部壓力(玻璃體)壓它;薄膜用接觸/附著貼在
   球面上。這條較重,適合之後接到 phaco 那半(可考慮 SofaCUDA 加速體積網格)。
