# 05 — FEM / Mass-Spring / ECM:核心差異 + 真實度對照

## 核心差異總表

| 面向 | **FEM** | **Mass-Spring** | **Enhanced ChainMail (ECM)** |
|---|---|---|---|
| 物理↔描述 | 物理式 | 中間(偏描述) | 描述式(+ 物理鬆弛) |
| 把物體看成 | 連續體(continuum) | 離散質點 + 彈簧 | 元素 + 幾何約束鏈 |
| 驅動方式 | 力 / 邊界條件 | **力驅動**(F=ma) | **位移驅動**(夾位置) |
| 核心運算 | 解全域方程 KU=F | 算力 → 積分(多時間步) | 夾位置 → 局部傳播(一個 pass) |
| 時間 | 靜態無 / 動態顯式 | 顯式積分 | 隱式(藏在處理順序) |
| 全域結構 | 需要(全域剛度矩陣) | 需要(全部節點/彈簧串列) | **不需要**(沿圖局部旅行) |
| 複雜度 | 高(~O(n²)–O(n³)) | 中(每步掃全部) | **線性於受影響元素數** |
| 參數可量測 | 是(E, ν) | 否(k 多靠調) | 否(約束靠映射/調) |
| 非均質 | 可(材料矩陣) | 較難(全域 k) | **可(就地約束)** |
| 穩定性 | 好(但慢) | 差(硬彈簧+大 dt 會爆) | **好**(一步到位,無積分) |
| 即時 | 否(除非降階) | 可 | **可** |

## 真實度(realism)排序

```
準確度:  FEM  >  mass-spring  >  ECM
速度/穩定: ECM  >  mass-spring  >  FEM
即時可用:  mass-spring ≈ ECM  >>  FEM
```

- **FEM**:物理最真,但即時用不了;適合離線規劃。
- **Mass-Spring**:真實度中等,即時可行;但有穩定性/網格各向異性問題。
- **ECM**:幾何近似(非真實物理量),但**視覺合理 + 穩定 + 可非均質 + 即時**;3D 穩定性勝 mass-spring。

## 選擇邏輯(由約束反推)

```
需要即時? ──否──► FEM(離線、最準)
   │是
   ▼
需要非均質 / 3D 高穩定? ──是──► ECM
   │否
   ▼
mass-spring(簡單、夠用;CCC 囊膜 Layer A 採此)
```

## 與 CCC 的關係

- **Layer A 囊膜變形**:Weber 2006 採 **mass-spring**(囊膜是「次要」,只需看起來會飄)。
- **若要模玻璃體(vitreous)等 3D 體積**:ECM 穩定性更佳(Schill 的規劃)。
- **撕裂本身**:三者都不直接處理拓樸改變 → 需獨立的撕裂 + remeshing(見 docs 06/07)。
