CCC 撕囊模擬的兩條路線:EyeSi vs INRIA

同一臨床任務(CCC 連續環形撕囊),兩種哲學。EyeSi(Mannheim / Männer 的 ViPA 組 → VRmagic)走描述式:手調規則模仿「撕痕往周邊跑」的外觀。INRIA(法國,SOFA → InSimo)走物理式:把成因(同心圓纖維各向異性)建進材料,現象自己湧現。分歧不在外觀,在有沒有把因果建進去——與各自的代價。

EyeSi 描述式 descriptive

Weber / Wagner / Männer 2006 · mass-spring + Indicator

# 撕痕方向 = 切平面上手調向量合成 PullDir = 器械拉的方向 DriftDir = 往周邊(徑向外,手調) Indicator = 膜瓣法線朝晶體? shear : rip newDir = rotate(CurrDir, driftA + pullA) # 撕往哪「不依賴物理」,由規則直接決定

把教科書的操作指南翻成幾何規則。可控、可教、即時上線;但沒有理論母體,換器械/拉法要重調。

INRIA 物理式 physical FEM

Comas 08 / Allard 09 / Dequidt 13 · 三角 FEM + argmax c

# 撕痕方向 = 從真纖維各向異性算出 每三角形帶纖維方向 θ(同心圓) c = (σ_d⊥ / σ̄_d⊥) · H((d·p) − cosθ_P) 裂向 = argmax c(負載/強度最大方向) # 等向退化 = 最大主應力準則(公認定律)

讀真實應力場,往「負載超強度最多」的方向裂。徑向弱 → 撕痕自然往周邊,不必手調 drift。物理最真,代價是工程量與 FPS。

先看這裡:公式與術語小抄(看不懂先讀這段)

下面整頁的專有名詞逐塊拆解。已經懂的可略過。

▍撕裂準則 c = (σ_d⊥ / σ̄_d⊥) · H((d·p) − cosθ_P)

問題:撕痕下一步往哪個方向 d 走、該不該撕?把每個候選方向都算一個分數 c,選最大的。三塊:

σ_d⊥ 垂直張力撐開裂縫的是垂直於撕痕線的張力(撕紙:紙往兩側被扯開,不是沿撕痕方向)。σ=應力。
σ̄_d⊥ 方向強度材料在那個方向撐得住的上限(bar=極限)。比值 σ_d⊥/σ̄_d⊥ = 負載/能耐,>1 就裂(像繩子承重超過上限就斷)。
H(·) 防回折閘Heaviside 階梯函數:括號 ≥0 輸出 1、否則 0(開關)。d·p=候選方向與上一步方向的夾角餘弦;cosθ_P=最大允許轉角。夾角太大(急轉)→ 分數歸零,讓裂縫平滑不急折。
argmax c選 c 最大的方向 = 在不急轉的方向裡,負載超過能耐最多的那個,材料最撐不住處先裂。

▍同心圓纖維各向異性

各向異性 = 強度隨方向不同(像木頭:順木紋好劈、橫木紋難砍)。囊膜的膠原纖維繞水晶體中心一圈圈排(像年輪)→ 圓周方向(沿纖維)強、徑向(往周邊、跨纖維)弱 → σ̄ 徑向特別小 → 撕痕天生偏往周邊。(臨床上「往周邊跑」的主推手其實是赤道懸韌帶的持續徑向張力;纖維各向異性是 INRIA 在其上的精緻化。)

▍最大主應力準則(Rankine)

固體力學最古老的斷裂判據:一點的應力隨方向而變,其中最大的那個純拉力叫最大主應力 σ₁;σ₁ 超過材料抗拉強度就裂,且裂縫垂直於 σ₁(玻璃/粉筆的脆性斷裂)。argmax c 關掉各向異性(σ̄ 各向相同)+ 關掉防回折閘,數學上就退化成 Rankine——所以它不是新 heuristic,是「Rankine + 纖維各向異性 + 平滑閘」的升級版,能退化回百年驗證的定律才可信。

▍Han 2021 離線 FEM 撕囊力學(CMPB 203:106025, PubMed 33714899)

四層 3D 水晶體模型(前囊+後囊+皮質+核)。判據 = Von Mises 變形能失效準則(元素何時起裂)+ 雙線性內聚律(bilinear cohesive)(前囊↔皮質介面怎麼一段段撕開,牽引力先升峰值再降到零=斷,曲線下面積=斷裂能)。用豬眼力感測鑷子校準(p=0.76/0.10 吻合)。結論:撕裂力 ~10–30 mN,最省力撕裂方向 θ₁=0°、θ₂=30°(速度不影響、直徑有影響)。這個「最省力方向」= Weber drift / INRIA argmax c 各自要捕捉的「撕痕有偏好方向」的物理背書。注意:此判據(Von Mises)≠ INRIA 的 argmax c(退化為 Rankine 最大主應力),是不同斷裂框架,勿混同。詳見 reference/7_han2021_fem_tearing.md。

▍其他引擎術語 (逐項展開見 engines/6_realtime_fem_pillars.md)

mass-spring質點+彈簧網格,力驅動(F=ma)。k 靠手調、隨網格而變,不是可量測的材料常數(對比 FEM 的 E/ν)。
FEM把連續體切成小元素解真應力/應變。輸入 E、ν 可量測,細分會收斂到連續解;準但慢(要解全域 KU=F)。
TLEDTotal Lagrangian(一切相對原始構型→導數預算一次)+ Explicit Dynamics(顯式逐節點→GPU)。讓真 FEM 即時。
co-rotational每元素扣掉剛體旋轉 → 在小應變下線性算力 → 再轉回。線性速度 + 大旋轉不失真(否則會憑空膨脹)。
matrix-free改用迭代 CG(只需 K·v,逐元素即時算),全域 K 從不成形 → 撕裂改拓樸只改元素 loop,免重組/重分解。

為什麼 INRIA 的 argmax c 準則「更對」(三層邏輯)

c = (σ_d⊥ / σ̄_d⊥) · H((d·p) − cosθ_P)    →   c > 1 就撕,方向 = argmax c
  1. 把因果建進去:囊膜纖維呈同心圓 → 徑向比圓周方向弱 → 撕痕天生易往周邊。Weber 手調一個 DriftDir 去模仿這現象;Allard 把造成現象的原因(同心圓纖維各向異性)建進材料,「往周邊跑」自己湧現。
  2. 每一塊都是標準斷裂力學:看垂直於撕痕的張力(σ_d⊥,撐開裂縫的是它)÷ 該方向的材料強度(σ̄_d⊥)→ 比值 >1 = 應力超過強度 = 裂;各向異性從 σ̄ 進來(纖維強、徑向弱);H(·) 防回折(只允許與上一步夾角 ≤ θ_P)。
  3. 等向時退化成公認定律:關掉纖維、關掉防回折,argmax c 數學上等於「最大主應力準則」——固體力學公認的脆性斷裂判據。能退化成已驗證的定律,邏輯上就可信。Weber 的手調 drift 沒有這個理論母體。

深入:INRIA 怎麼化解「撕裂讓隱式失效」(即時性攻防)

Weber 的論點(2006):隱式積分省時,靠把要解的大矩陣 K 預先分解(factorize,≈預先反轉)存起來重複用。但撕裂一直改網格 → 存好的分解馬上失效 → 每步重算(很貴)→ 隱式優勢沒了。所以「會撕的膜用顯式反而划算」。

INRIA 不反駁這事實,用三層把它「溶解」:

第 1 層 · Comas 2008(TLED):同意,那就用顯式——但保住真物理

TLED = 顯式中央差分、逐節點獨立,不組任何全域 K,撕裂只改元素清單。跟 Weber 同招(沒有 K 就沒有分解會失效),差別只在力從真應變場算、非彈簧手調。顯式要小 dt,但軟組織剛度低→臨界 dt 大→不痛;GPU 平行→數萬元素即時。

第 2 層 · Matrix-free CG:非要隱式的穩定?那就「永遠不分解」

接觸/大 dt/穩定有時真需要隱式。洞見:「分解失效」只在你「預先組裝+分解 K」時才發生。改用迭代解法共軛梯度(CG)——它只需要 K·v(K 乘向量),而 K·v 可逐元素即時算,K 從頭到尾不成形。撕裂改拓樸 = 只改「loop 哪些元素」。沒有分解,就沒有分解會失效——Weber 那條死路根本不存在。

第 3 層 · Courtecuisse 非同步預條件子:隱式迭代在異質組織會變慢(最硬一關)

新問題:CG 在軟硬不均組織(囊膜軟、核硬)上收斂慢→隱式又慢回去。預條件子能加速收斂,但算它貴、拓樸一變又要重算。巧思:預條件子丟背景執行緒非同步算,主迴圈用「稍微過期」的版本(組織變形夠慢,稍舊仍好用)。→ 隱式穩定 + 收斂快 + 即時,撐起 Dequidt 2013 的接觸 + 器械互動(摩擦接觸;器械 IR 光學追蹤,無力回饋裝置)。

🔑 三層答案:(1) 乾脆用顯式(TLED,無 K);(2) 非要隱式就 matrix-free(永不分解);(3) 迭代慢就非同步預條件子。Weber「會撕就用顯式」在 2006 是對的取捨;INRIA 用 GPU + 迭代 + 非同步,把「隱式的穩定」也一起拿回來。詳見 reference/3_inria_fem_lineage.md(四瓶頸→四解法)、reference/4_inria_fem_realtime.md。

核心洞見:不是競爭,是同一問題在不同約束下的兩個答案

兩條路線不是誰對誰錯,而是在「即時 vs 物理真實」的取捨上站在不同位置:

· 要教學 / 訓練即時上線 → Weber 路線就夠(EyeSi 已用 McCannel 2013 證明能降 68% 錯誤撕囊率)。理解撕囊力學不需要 3D FEM。

· 要物理最真 / 完整術式(phaco + IOL) → INRIA 路線;正確做法是直接用 SOFA(Dequidt 系統就建在上面),而非手刻 FEM。

兩者其實會師:Han 2021 離線 FEM(Von Mises + 內聚律 + 豬眼驗證)算出「最省力撕裂方向」(θ₁=0°/θ₂=30°),替 Weber 憑觀察塞進去的「撕痕有偏好方向」提供物理背書——描述式當年猜對的,物理式後來證實了。反差:描述式在純流暢度仍佔優(但 INRIA 的 5fps 只是 IOL 那步——phaco 其實 80fps、撕囊即時,現代 GPU 更快)。
