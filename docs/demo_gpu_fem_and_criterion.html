2 · Comas 在解什麼:scatter → gather

FEM 的每一步要算「每個節點受多少力」。而一個節點的力 = 所有碰到它的元素各自貢獻的總和。問題出在:一個節點被很多元素共用。下圖中,中央節點 N 同時屬於三角形 A、B、C、D。

圖 A — 為什麼不能天真平行:共用節點 N 被多個元素 thread 同時累加,產生 race condition。

Comas 的解法是拆成兩段 kernel,中間插一個「每個元素有自己專屬格子」的緩衝,讓任何時刻沒有兩條 thread 寫同一個位置:

圖 B — 兩段 kernel:先 scatter(元素各寫自己的格子),再 gather(每個節點收自己那一份)。任何時刻「一個位置只有一條 thread 寫」。
一個生活比喻。 4 個人(元素)各自要付錢給幾位共用的朋友(節點)。
天真做法:大家同時把錢塞進同一個共用撲滿 → 手撞手、數字算錯(race)。
scatter/gather:每個人先把錢裝進自己貼了標籤的信封(scatter,各寫各的);然後每位朋友去收寄給自己的那些信封再加總(gather)。全程沒有兩隻手伸進同一個罐子。

代價是多用一點顯存(每元素的私有格子)+ 一張「節點→鄰接元素」連接表。因為 TLED 的 Total-Lagrangian 把連接關係預算一次、之後不變,這張表幾乎免費 —— 這也是為什麼這招在 GPU 上這麼划算。

順帶:co-rotational 與 TLED 是兩條不同引擎

co-rotational + 隱式TLED + 顯式
每步解線性系統?要(CG)不用
材料線性彈性非線性超彈性
時間步 Δt可較大必須很小(CFL)
平行度中(CG 有相依)極高(節點全獨立)

兩者都跑在 GPU 上,scatter/gather 這招在兩者算「力」時都用得到。你剛 benchmark 的 raptor 是 co-rotational + 隱式的 GPU 版。

3 · argmax c 撕裂準則,逐符號拆解

公式(你 ccc_method/4 第 22 行):

c(d) = ( σ_d⊥ / σ̄_d⊥ ) · H( d·p − cos θ_P )      對每個候選方向 d 算一次
撕裂:若 max_d c(d) > 1 → 沿 argmax_d c(d) 那個方向撕
圖 C — 裂尖 T 處:同心圓纖維讓徑向 r 弱、圓周 f 強;候選方向 d 在 θ_P 扇形內才有效;真正撐開裂縫的是垂直於 d 的張力 σ_d⊥;argmax c 選「負載/強度」最大者(通常沿最弱的徑向)。回折方向被 H 閘門歸零。

逐塊解釋你問的每一點

Q:為何 σ_d⊥ 是「應力」、σ̄_d⊥ 是「材料強度」?單位合理嗎?

符號是什麼單位
σ_d⊥裂尖處垂直於 d 方向實際承受的張應力(外加負載造成)Pa = N/m²
σ̄_d⊥材料在同一方向能承受的強度上限(材料屬性,纖維方向不同而異)Pa = N/m²
c = σ_d⊥ / σ̄_d⊥負載 ÷ 強度 = 用掉幾成的容許量無單位(Pa/Pa)
兩個都是應力(Pa),相除得到無因次的純數 —— 這正是為什麼門檻是乾淨的「1」。 這在工程上就是安全係數的倒數 / 利用率(utilization ratio):c=0.5 表示只用了一半強度,c=1 剛好用滿,c>1 表示負載超過強度 → 裂。單位完全一致、合理。

Q:H(d·p − cos θ_P) 的物理定義?θ_P 從哪來?

  • H 是 Heaviside 階梯函數:H(x)=1 若 x≥0,否則 0。是一個開/關閘門,只輸出 0 或 1,乘上前面的比值 = 「這個方向到底算不算數」。
  • d·p = cos(d 與 p 的夾角)(兩者都是單位向量)。所以 d·p ≥ cos θ_P ⟺ 夾角(d,p) ≤ θ_P。也就是:只有跟上一步方向 p 夾角不超過 θ_P 的候選 d,閘門才開(H=1);偏太多的 d 被歸零。
  • θ_P 是一個建模參數 —— 不是從第一原理算出來的,是「每一步裂縫最多能轉多少角度」的上限,由建模者設定 / 依材料行為校調。它把「真實裂縫走得平滑、不會突然急轉」這個物理事實編碼進準則。

Q:什麼是「回折」?

✓ 平滑前進(H=1,允許)
新方向 d 跟上一步 p 幾乎同向,夾角小 → 裂縫像一條連續的線慢慢彎。真實材料就是這樣裂的。
✗ 回折 / backfold(H=0,擋掉)
某個方向的應力剛好很高,但它指向後方或急轉(跟 p 夾角 > θ_P)。若不擋,裂縫會鋸齒亂折、甚至往回走 —— 物理上不可能。H 閘門把這種候選歸零。

「回折」= 裂縫路徑突然反折、急轉、甚至 U-turn。H 閘門的唯一任務就是禁止它,保證撕痕平滑連續。

Q:算出來的 c 是什麼單位? → 無因次純數。(Pa/Pa)×(0 或 1)= 純數。所以能直接和「1」比大小。

Q:為什麼這個公式是「對」的? 四個理由疊起來:

  1. 看對了力:撐開裂縫的是垂直於前進方向的張力(裂縫面法線 = d⊥),不是 d 方向的力。σ_d⊥ 抓的正是這個。
  2. 比對了強度:除以同方向的材料強度 σ̄_d⊥。各向異性從這裡進來 —— 徑向強度小 → 徑向的 c 容易 > 1 → 撕往周邊(囊膜真實現象自己湧現)。
  3. 選對了方向:argmax 選「負載/強度」最大者 = 材料在最脆弱/最超載的方向先裂。H 閘門再排除不物理的回折。
  4. 退化成公認定律:關掉纖維(σ̄ 各方向相同、不防回折),argmax c 數學上等於「最大主應力準則(Rankine)」—— 固體力學公認的脆性斷裂判據。
🔑 第 4 點是關鍵:它不是憑空 heuristic,而是「最大主應力準則」的各向異性升級版。等向 = 已驗證的經典定律;加纖維 = 描述囊膜。能退化成公認正確的定律,邏輯上就可信 —— 這是 Weber 手調 DriftDir 沒有的理論母體。
⚠️ 一個坑(你 reference/7_han2021 標註過):argmax c → Rankine 是講 INRIA / Allard 這條;Han 2021 是另一套(Von Mises 畸變能 + cohesive law),兩者是不同的斷裂框架,不可混同。
