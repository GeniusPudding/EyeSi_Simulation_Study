# 04 — FEM(有限元素法):概念與為何即時用不了

來源:Schill 2001 §3.1。
**一句話**:把物體當**連續體**,切成小元素、在元素內用內插函數逼近解,組裝成全域方程組求解。最準,但最貴。

---

## 1. 概念

- FEM 嚴格說**不是建模技術,而是「解某類數學問題」的方法**(把彈性理論問題離散化)。
- 把物體切成簡單規則的**小元素**(三角形/四面體/立方體),元素在**節點(node)**相接。
- 元素內用**形狀函數(shape functions,通常多項式)**內插出解;元素越細 → 逼近越準。
- FEM 把物體當**連續體**(continuum),保證元素邊界連續。

## 2. 怎麼算變形(最小位能原理)

受力物體會變成**位能最小**的形狀。對位移微分、令為零 → 線性方程組:

$$K\vec{U} = \vec{F}$$

- **K** = 剛度矩陣(裝幾何 + 材料參數 E、ν),很大但稀疏;**U** = 節點位移;**F** = 外力。
- 套邊界條件後,用 Gauss / Cholesky 分解或共軛梯度法解。

**動態 / 非線性**:加質量與阻尼項,變成與牛頓運動方程同形的二階微分方程:

$$M\ddot{U} + D\dot{U} + K\vec{U} = \vec{F}$$

> 注意:這與 mass-spring 的矩陣式**長得幾乎一樣,但意義不同**——
> FEM 把物體當連續體做**幾何離散化**;mass-spring 把物體理想化成**離散質點**(問題本身離散化)。
> **兩者在「理想化」那一步就分家了。**

## 3. 為何即時用不了

- 要解 $KU=F$ 這種**全域**線性方程組(大矩陣分解/求逆),複雜度遠超線性(常 O(n²)~O(n³))。
- 動態問題更慢(要對時間積分)。
- 為了即時,常做簡化:**假設靜態/準靜態**(拿掉時間)、**假設線性彈性**(簡化材料定律)——
  但這些簡化會把方法**推向描述式那端**,且對高度可變形物體會產生**物理不正確、視覺干擾**的假象
  (Weber 2006 明確指出這點)。

---

## 真實度(realism)

- **物理地位**:最物理。基於連續體力學,參數 E、ν **可量測 → 易驗證**。
- **準確度**:三者最高。
- **代價**:運算極貴、建模複雜、**即時做不到**(除非犧牲精度做線性化/降階)。
- **適用**:離線手術規劃、需要物理正確預測的場合;**不適合即時互動的高度變形組織(如撕囊)**。

### 一句話定位
> CCC 撕囊需要即時 + 拓樸改變 + 高度變形 → **FEM 不適用**,故 EyeSi/Weber 採 mass-spring + 描述式撕裂。
