Weber 2009 物理版:應變場驅動裂向

底層 mass-spring;鑷子拉 → 整片瓣膜掀起,且只有持續往外拉更遠才裂一步、停手就停(自限,近似 2009 斷裂準則);裂向 = 與你拉的方向垂直(= 應變最小方向 = Rankine)。

兩種器械分工:
• 鑷子(F):移到某條裂痕的瓣膜上按住往外拉 → 整片掀起;要裂縫前進就持續往外拉更遠,停手/不再拉更遠就停(只影響那一片)。
• 針(N):圈圈就是尖端,方向鍵/游標直接帶著切,切到哪裂到哪(方向受應變場微彎);可在不同位置各切一條。
打開應變場熱圖:被拉扯處紅、鬆弛處藍。
鍵盤:方向鍵移動(+Shift)/ 空白鍵操作 / T 開切口 / C 沿裂痕乾淨切開(整片脫離、零遺留) / F/N 器械 / R 重置 / S/V 開關。
