## A. 「各向異性(anisotropy)」這個詞

- **各向** = 每個方向;**異性** = 性質不同 → **各向異性 = 性質隨方向而不同**。
- 反義:**各向同性(isotropy)** = 每個方向都一樣(如均質橡膠、鋼)。
- 字源:希臘 an(不)-iso(相等)-tropos(方向)= 「方向不對稱」。
- 例:木頭(順木紋好劈、橫木紋難砍)、纖維增強材、肌肉、囊膜(膠原纖維呈同心圓 → 順纖維強、橫向弱)。

## B. KU=F 為何「3N 個 DOF 互相有影響」(耦合的物理與稀疏性)

**先定義**:N 個 3D 節點,每節點 3 DOF(x,y,z 位移)→ 共 **3N 個未知數**,疊成向量 U;K 是 (3N)×(3N)。`K[i][j]` = 「DOF j 動一單位、在 DOF i 生出多少力」。

**為何耦合(物理)**:網格是**連在一起**的。動節點 j → 拉伸/壓縮**所有含 j 的元素** → 那些元素也含 j 的鄰居 → 元素變形對它**全部角節點**生力,包括鄰居。所以「動 j」在 j 與其鄰居都生力 → `K[i][j]≠0`。

**關鍵:是局部耦合(稀疏),不是每個都直接影響每個**:
- `K[i][j]≠0` **只當 DOF i、j 共享同一元素**(是鄰居);距離遠的 `K[i][j]=0`。→ **K 大部分是零(稀疏)**,每個節點只直接連它那幾個鄰居。
- 同一節點的 3 個 DOF(x,y,z)彼此也耦合:因泊松效應與元素幾何,往 x 拉會在 y、z 生力。

**為何非「一起解」不可**:平衡是**全域條件**——每個節點都要同時力平衡。移 j 影響鄰居、鄰居影響鄰居的鄰居…一條鏈把全網間接連起來 → 必須讓所有節點的平衡**同時成立** → 解耦合系統。
> 對比:**顯式**不解這個耦合系統,只算「當下受力」往前推一小步,讓耦合透過許多小時間步**一步傳一格**地擴散;**隱式**一步就把全域耦合解開。這正是兩者的根本差別。

## B.5 這些應變公式哪來的(F、∇u、ε、E 一條線,別當四個獨立公式)

1. **變形梯度 F = 形變映射的梯度**。材料點原始位置 X、變形後 x=x(X);`F = ∂x/∂X`。意義:原始小向量 dX 變成 dx = F·dX。因 x = X + u(位移),故 **F = I + ∇u**——F 和位移梯度 ∇u 只差一個單位矩陣。那個 **I 是「原向量本身」**:沒變形時 u=0 → F=I(dx=dX)。1D 拉 10%:∇u=0.1(變化率)、F=1.1(長度比)。(這回答「F 哪來的、為何差一個 I」。)
   > ⚠️ **撞名警告**:這個「變形梯度 F」和 `KU=F` 裡的「外力向量 F」是**完全不同的兩件事**,只是都用字母 F。前者是描述局部變形的張量 ∂x/∂X,後者是節點受力。別搞混。
2. **精確應變 = 長度平方變化**。小段 dX 變形後 dx=F·dX,長度平方變化:
   `|dx|² − |dX|² = dXᵀ(FᵀF − I)dX = 2·dXᵀ E dX`
   → **Green-Lagrange 應變 E = ½(FᵀF − I)** 就是「精確的長度平方變化」。剛體旋轉 F=R → FᵀF=RᵀR=I → **E=0(任何角度都精確為零)**。(這回答「為何又有 Green-Lagrange」。)
3. **線性應變 ε = E 的小變形近似**。把 F=I+∇u 代入:
   `FᵀF − I = ∇u + ∇uᵀ + ∇uᵀ∇u`  →  `E = ½(∇u+∇uᵀ) + ½∇uᵀ∇u = ε + (二次項)`
   丟掉二次項 `½∇uᵀ∇u`(小變形可忽略)→ **ε = ½(∇u+∇uᵀ)**。ε 不是憑空定義,是 **E 砍掉二次項**。
4. **為何 ε 取「對稱部分」**:第 2 步顯示「長度變化到一階只由對稱部分決定」,反對稱部分 ω=½(∇u−∇uᵀ) 是旋轉、不改長度。任意矩陣 = 對稱+反對稱(純代數恆等式)→ **∇u = ε(應變) + ω(旋轉)**。
5. **大旋轉為何 ε 錯**:ε 丟掉的那個二次項,對純旋轉剛好是「補回 E=0 所需的量」。丟了它,ε 在大旋轉就留下假應變(= §C 算的 cosθ−1)。**ε 的誤差 = 被丟掉的二次項。**
6. **極分解 F = R·U**:把這個 F(=I+∇u)拆成旋轉 R × 純拉伸 U;co-rotational 抽的就是這個 R(見 §E)。

> 一條線:`u → ∇u → F=I+∇u → C=FᵀF → E=½(C−I)`;而 `ε = E 砍二次項 = ∇u 的對稱部分`。

## C. 線性應變公式為何這樣寫?旋轉不是不產生力嗎?sin 哪來的?(三題合一,附算例)

**真實物理**:剛體旋轉**不儲存彈性能 → 不產生內力**。這你直覺是對的。問題在**線性應變公式算錯了**。

**線性(小)應變**:`ε = ½(∇u + ∇uᵀ)`(位移梯度的對稱部分)。為何這樣寫?因為位移梯度可拆:
```
∇u = ε(對稱=應變) + ω(反對稱=旋轉)
```
**小位移**時這乾淨地把「拉伸」和「旋轉」分開,線性彈性只取 ε → 對小旋轉,ε≈0、旋轉不生力,一切正確。**它是為小變形設計的一階近似,且線性 → 整個 KU=F 是線性 → 解得快**(這就是「為何要這樣寫」:便宜)。

**大旋轉為何崩(具體算例)**:2D 剛體旋轉 θ,點 X 移到 x = R·X,
```
R = [ cosθ  −sinθ ]     ← sin/cos 就是從「旋轉一個向量」來的(基本三角)
    [ sinθ   cosθ ]
u = x − X = (R − I)·X
∇u = R − I = [ cosθ−1   −sinθ ]
             [  sinθ    cosθ−1 ]
```
取對稱部分(線性應變):off-diagonal 的 −sinθ 與 +sinθ **相消** →
```
ε_xx = ε_yy = cosθ − 1        ε_xy = 0
```
- **小 θ**:cosθ−1 ≈ −θ²/2 ≈ 0 → 應變≈0 ✔ 旋轉幾乎不生假力(所以小變形用線性沒問題)。
- **θ=90°**:cosθ−1 = 0−1 = **−1** = **−100% 壓縮應變!** 線性彈性以為物體被壓扁 → **生出巨大假壓力**。← 這就是「大旋轉失真」的數學根源。

**sin 哪來的**:來自旋轉矩陣 R(轉一個向量必用 sin/cos)。「小角時 sinθ≈θ、cosθ≈1−θ²/2」是小角近似;正是 `cosθ−1≈−θ²/2` 這個**二階小量**讓小旋轉的假應變可忽略,大旋轉就不行。

### ★ 核心疑點:既然拆成「對稱=應變 + 反對稱=旋轉」,對稱部分不就該是純應變、自動排除旋轉嗎?
**拆解本身是精確的代數;錯的是「對稱部分 = 純應變」這個「認定」——它只在小旋轉下成立。**
- 真旋轉矩陣 `R=[cosθ,−sinθ;sinθ,cosθ]` 是**非線性**的(cos/sin);而對稱/反對稱拆解是**線性**的 → 線性拆解只能「到一階」把旋轉裝進反對稱那半。
- **小 θ**:R ≈ I+[0,−θ;θ,0] → ∇u=R−I ≈ **純反對稱** → 對稱部分 ε≈0 ✔(旋轉全被反對稱 ω 收走)。
- **大 θ**:cosθ≠1 → R−I 有**非零對稱部分**(cosθ−1)→ **旋轉「漏」進了對稱部分 ε**、被誤當應變。反對稱 ω 只裝得下旋轉的一階近似,裝不下的殘量就溢進 ε。
- 對回推導:`E = ε + ½∇uᵀ∇u`。純旋轉時 `½∇uᵀ∇u = (1−cosθ)I`,**剛好抵掉** `ε=(cosθ−1)I` → `E=0`。**ε 的假應變 = 它丟掉的那個二次項**;E 沒丟,所以 E 對任何旋轉都精確為零。

**「旋轉是非線性」到底指什麼?(旋轉不就是線性變換嗎?)**
你說得對:`x = R·X` 對**位置 X** 確實是線性映射(R 是矩陣)。「非線性」不是指這個,是指:
- **旋轉隨其角度 θ 是非線性的**:R(θ) 的元素是 cosθ/sinθ、假應變 cosθ−1 都非線性於 θ。不能把「大旋轉」當成「小旋轉的線性倍數」(cos/sin 會彎回來)。
- **「所有旋轉」構成一個彎曲的集合(SO(n) 流形)**,不是平的線性空間。R(θ₁)·R(θ₂)=R(θ₁+θ₂),但 R(θ₁)+R(θ₂) 不是旋轉。
- **最精準**:真旋轉的「不變形」條件是 **RᵀR=I(二次/非線性)**;線性應變隱含用的卻是它的一階近似 **R+Rᵀ=2I**——兩者只在 R≈I(小旋轉)吻合。線性應變用「平的切平面」去近似那個彎面,離原點(大旋轉)就失準。
> 所以:**旋轉這個映射是線性的;非線性的是「旋轉隨角度的變化」和「旋轉集合的彎曲」。**

**嚴格版(假應變是 O(θ²)、真旋轉是 O(θ))**:對 R(θ)=[[cosθ,−sinθ],[sinθ,cosθ]],∇u=R−I,
```
ε = ½(R+Rᵀ)−I = (cosθ−1)·I            # 對稱部分(被誤當應變)
ω = ½(R−Rᵀ) = [[0,−sinθ],[sinθ,0]]     # 反對稱部分(旋轉)
```
泰勒展開:`cosθ−1 = −θ²/2 + O(θ⁴)` → ‖ε‖ = **O(θ²)**;`sinθ = θ − O(θ³)` → ‖ω‖ = **O(θ)**。
→ 假應變/真旋轉 ~ θ/2 → 0(當 θ→0)。**小角:假應變是二階小量、可忽略;大角:假應變 O(1)、爆炸。** 這就是「小角落 ω、大角漏進 ε」的嚴格陳述。

| θ | 假應變 ε = cosθ−1 | 旋轉量 sinθ | 假應變/旋轉 |
|---|---|---|---|
| 5° | −0.0038(0.38%) | 0.087 | 0.044 |
| 30° | −0.134(13%) | 0.500 | 0.27 |
| 90° | −1.000(100%) | 1.000 | 1.0 |

> 一句話:**拆解沒錯,錯在「對稱部分=純應變」是個近似**——線性拆解只能一階把旋轉擋在反對稱半,大旋轉就擋不住、漏進對稱半。

**所以三題的答案**:公式那樣寫是為了**便宜的線性**、且對小變形正確;旋轉**本該不生力**,是線性近似**誤算**出假力;修法 = 非線性應變(D)或 co-rotational(E)。

## D. 全非線性 FEM 具體長怎樣(幾何 + 材料非線性)

用**不受旋轉污染的非線性應變**,代價是每步要 Newton 迭代:

1. **精確應變 = Green-Lagrange**:`E = ½(FᵀF − I) = ½(C − I)`。因 C=FᵀF 把旋轉扣掉(RᵀR=I),**純旋轉 → E=0、零假力**(對照 C 的 −100% 假應變,這裡正確)。
2. **非線性材料**:超彈性 `S = 2·∂Ψ/∂C`(Ψ=應變能函數)。
3. **內力是位移的非線性函數** `F_int(u)`——**不再是常數 K 乘 u**。
4. **平衡 `F_int(u) = F_ext` 是非線性方程組** → 用 **Newton-Raphson** 解:
```
每個時間步:
  猜 u → 算殘差 r = F_ext − F_int(u)
  算切線剛度 K_tan = ∂F_int/∂u  (在當前 u 附近線性化)
  解 K_tan·Δu = r   (一個線性系統,像 KU=F 但矩陣是切線剛度)
  u ← u + Δu
  重複到 r 夠小(通常幾次收斂)
```
→ **每個時間步內含多次 Newton 迭代,每次都重算切線剛度 + 解一個線性系統**。最準,但貴。
> **三種選擇的定位**:全非線性(準·貴,Newton)> **co-rotational**(便宜地只修旋轉、應變仍在共旋座標下線性)> **TLED 顯式**(乾脆不解方程)。軟組織「大旋轉、但應變中等」→ co-rotational 性價比最高。

## D.5 別混淆:Green-Lagrange(應變量度) vs Total Lagrangian(參考構型)

兩個都有「Lagrange」,但是**兩個不同的軸,可自由組合**:

| 軸 | 是什麼 | 選項 | 決定 |
|---|---|---|---|
| **應變量度** | 「用哪條公式量應變」 | Green-Lagrange `E=½(C−I)` / 線性 `ε` / … | 準不準、旋轉可不可靠 |
| **參考構型(Lagrangian 描述)** | 「相對哪個構型量一切」 | **Total**(相對原始 t=0)/ **Updated**(相對上一步) | 形狀函數導數要不要每步重算 |

- **Green-Lagrange** = 應變的**內容**(量什麼);**Total Lagrangian** = 求導/積分的**參考框**(相對誰)。
- Total = 相對永不變的原始構型 → 形狀函數導數是**常數、預算一次**(這就是 TLED 快的原因,見 [`6_realtime_fem_pillars.md`](6_realtime_fem_pillars.md) §1)。
- **常一起用**:TLED = 「Total Lagrangian 框 + 顯式積分」,在該框下算應力。co-rotational 是**另一種**處理大旋轉的框(每元素抽 R,見 §E)。

> 記法:**Green-Lagrange 回答「應變公式是哪條」,Total/Updated Lagrangian 回答「相對哪個構型算」。** 別把「用了 Green-Lagrange」和「用了 Total Lagrangian」當同一件事——一個是量度、一個是參考框。

## E. co-rotational 每元素每步「如何抽出剛體旋轉 R」

R 是「F 裡的旋轉部分」。兩種實務做法:

**做法 1:極分解(polar decomposition)** `F = R·U`
- F = 旋轉 R(正交,RᵀR=I)× 對稱拉伸 U。R 即所求。
- 算法:對 F 做 SVD `F = W Σ Vᵀ` → `R = W Vᵀ`(或用 Higham 迭代快速求極分解)。

**做法 2:從邊向量建座標框(三角形/四面體,便宜常用)**
```
取元素當前的邊向量(如 e1=x2−x1, e2=x3−x1)
Gram-Schmidt 正交化 → 當前正交框 [a1 a2 a3]
R = 當前框 · (靜止框)⁻¹        # 當前方位相對靜止方位轉了多少
```
- 就是「拿元素**現在的朝向** vs 它**靜止時的朝向**,差多少 = R」。
- 便宜(幾個內積/外積),即時 FEM 常用(Müller/Etzmuß/Hauth 系)。

**抽出後**:用 Rᵀ(=R⁻¹)把當前位置轉回靜止方位 → 此時只剩真拉伸 → 套線性應變/線性剛度算力 → 再用 R 把力轉回世界座標。

## F. CG(共軛梯度)每次迭代具體在做什麼

**要解** `A·x = b`(A 對稱正定;隱式 FEM 的 A = M/Δt² + K)。

> **這跟原始 KU=F 什麼關係?不是新體系。** `KU=F` 是**靜態**平衡(無時間、無質量:剛度×位移=力,解「靜止後的形狀」)。加上牛頓動力學 `Mü+Ku=f`、再用**隱式**時間離散、整理成「解這一步的位移增量 Δu」,就得 `(M/Δt²+K)·Δu = 殘差`。**同一個 K、同一種全域耦合系統,只是多了質量/時間項 M/Δt²、且改解增量 Δu。它是 KU=F 的「動態時間步」版,不是另一個體系。**(確切係數依積分法,示意用 M/Δt²+K。)

**直覺**:解 Ax=b 等於**找一個碗形二次函數的谷底** `f(x) = ½xᵀAx − bᵀx`(它的最低點就是 Ax=b)。CG = 聰明版的「下坡找谷底」。

**完整演算法(可直接照抄實作)**:
```
解 A·x = b:
  x = 0                      # 初始猜測
  r = b − applyA(x) = b      # 殘差(x=0 時 = b)
  p = r                      # 第一個搜尋方向
  rsold = r·r                # 殘差平方(純量)
  重複:
    Ap = applyA(p)           # ← 唯一碰「矩陣」的地方(matrix-free)
    α  = rsold / (p·Ap)      # 步長:沿 p 走多遠到最低
    x  = x + α·p             # 更新解
    r  = r − α·Ap            # 更新殘差
    rsnew = r·r
    若 √rsnew < 容差 → 收斂,結束
    β  = rsnew / rsold       # 共軛係數
    p  = r + β·p             # 新共軛方向(混入舊方向,不走回頭路)
    rsold = rsnew
```
每次迭代只做:**1 次 applyA + 2 個向量內積 + 幾個向量加減**,全部 O(N),便宜。

**matrix-free 的關鍵 = applyA(v):不組 K,逐元素算 A·v**
```
applyA(v):
  result = (1/Δt²)·M·v            # 質量項(M 對角,逐節點乘,便宜)
  對每個元素 e:
    v_e = 從 v 取出元素 e 那幾個節點的分量        # gather
    Ke  = 元素剛度(co-rotational: Ke = Rᵀ·K_local·R,用當前旋轉 R)
    f_e = Ke · v_e                              # 一個小矩陣乘(例 12×12)
    把 f_e 加回 result 中元素 e 節點的位置        # scatter-add
  回傳 result
```
= 「對每個元素做一個小矩陣乘、散加回去」——**全域 A/K 從不成形**。撕裂改拓樸 = 改「對哪些元素 loop」而已。

**在 SOFA 裡怎麼落地**:`applyA` 就是 ForceField 提供的 `addDForce`/`addMBKv` 方法(給它 v、回傳 A·v);`CGLinearSolver` 跑上面那個 CG 迴圈、每次迭代呼叫它。**你不必自己組矩陣**。
- **收斂**:普通梯度下降來回鋸齒;CG 選共軛方向 → 不重複下已處理的方向 → 少很多步。條件好幾次就夠;**預條件子**讓碗更圓 → 更少迭代(異質組織碗很扁 → 非同步預條件子)。

> 一句話:CG = 上面十來行迴圈,唯一碰矩陣處是 `applyA(p)`,而 applyA 逐元素算 → K 不必組出來。

### 真數字範例:用 CG 解一個 2×2 系統(囊膜迷你版)
設 `A=[[4,1],[1,3]], b=[1,2]`(A 對稱正定;想成一個 2-DOF 迷你囊膜的 `M/Δt²+K`,b=殘差,x=Δu)。真解 `x = A⁻¹b = [1/11, 7/11] = [0.0909, 0.6364]`。
```
CG(x₀=0):
  r₀ = b − A·0 = [1,2];  p₀ = [1,2];  rsold = r₀·r₀ = 5
  ── 迭代 1 ──
  Ap₀ = A·[1,2] = [6,7]                         # ← 唯一碰矩陣處(matrix-free)
  α₀  = 5 / (p₀·Ap₀) = 5/20 = 0.25
  x₁  = [0.25, 0.5]
  r₁  = [1,2] − 0.25·[6,7] = [−0.5, 0.25];  rsnew = 0.3125
  β₀  = 0.3125/5 = 0.0625;  p₁ = r₁ + β₀·p₀ = [−0.4375, 0.375]
  ── 迭代 2 ──
  Ap₁ = A·[−0.4375,0.375] = [−1.375, 0.6875]
  α₁  = 0.3125 / (p₁·Ap₁) = 0.3125/0.8594 = 0.3636
  x₂  = [0.25,0.5] + 0.3636·[−0.4375,0.375] = [0.0909, 0.6364]   ← 正好=真解!
  r₂  = [0, 0] → 收斂
```
- **理論**:N×N 系統 CG 最多 N 步精確收斂 → 2×2 剛好 2 步。每步只碰 **1 次 A·p**(matrix-free 就在此逐元素算)。

**圖示(碗形等高線,CG 兩步走到谷底)**:
```
  x₂ ↑
     │      ____                ● = 真解/谷底 [0.09, 0.64]
     │    ╱  ● ╲                x₀=(0,0) ─p₀→ x₁=(0.25,0.5) ─p₁→ x₂=●
     │   │ ╲__╱ │               第 1 段沿殘差方向;第 2 段用「共軛」方向直插谷底
     │    ╲____╱                (共軛 = 不破壞第 1 段已下好的方向 → N 步到底)
     └──────────────→ x₁
```

## G. 手算範例:一個囊膜三角形剛體轉 90°(看假應變怎麼冒出來、co-rotational 怎麼修)
> **教學範例(非論文原文)**,把 §C–§E 落成真數字。囊膜 = 2D 三角 FEM。

**靜止三角形**:X₁=(0,0), X₂=(1,0), X₃=(0,1)。
**剛體轉 90°**(R=[[0,−1],[1,0]],純旋轉、零拉伸),當前位置 x_i = R·X_i:
```
x₁=(0,0),  x₂=(0,1),  x₃=(−1,0)
```

**① 變形梯度 F**(線性三角形:F = 當前邊矩陣 · 靜止邊矩陣⁻¹):
```
靜止邊 E₂=(1,0), E₃=(0,1)  → D_rest = [[1,0],[0,1]] = I
當前邊 e₂=(0,1), e₃=(−1,0) → D_curr = [[0,−1],[1,0]]
F = D_curr · D_rest⁻¹ = [[0,−1],[1,0]] = R   ✓ (純旋轉,F 就是 R)
```

**② 線性應變 ε(會出事)**:∇u = F − I = [[−1,−1],[1,−1]]
```
ε = ½(∇u+∇uᵀ) = ½·[[−2,0],[0,−2]] = [[−1,0],[0,−1]]
→ ε_xx = ε_yy = −1 = 「x、y 各縮 100%」的假應變!  但三角形只是轉了、沒縮。
→ 線性應力 σ=C:ε 巨大 → 巨大假力想把三角形「撐回去」。
```

**③ Green 應變 E(正確)**:`E = ½(FᵀF−I) = ½(RᵀR−I) = ½(I−I) = 0` ✓ 零應變、零力。

**④ co-rotational 怎麼修**:
```
抽旋轉 R = F(純旋轉);把當前位置轉回靜止方位 x'_i = Rᵀ·x_i:
  x'₁=(0,0), x'₂=(1,0), x'₃=(0,1)   = 正好回到靜止位置!
共旋位移 u' = x'−X = 0 → 線性力 f' = Ke·u' = 0 → 轉回 f = R·f' = 0   ✓ 零力,正確。
```

**對照(有真拉伸時 co-rot 不會漏)**:若改成 x₂=(1.1,0)(x 拉 10%、不轉)→ ε_xx=0.1=真 10% 應變;co-rot 因 R=I 得同結果。→ **co-rot 只扣旋轉、不吃掉真拉伸。**

> 核心:線性應變是**盲的公式**,只看「點移了多少」,分不清「移動是因為轉還是因為拉」。90° 旋轉讓角點移了一大段,公式就當成拉伸(−100%)。co-rotational 先把旋轉扣掉,公式看到的就只剩真拉伸。

## 串起來:一個 CCC 撕囊幀怎麼跑(把 B–F 接起來)
```
1. 每元素抽 R(E) → 轉回靜止方位算線性各向異性力 → 轉回 → 得 F_int(co-rotational)
2. 隱式:組出 (M/Δt²+K)·Δu = 殘差,用 CG(F)解;每次迭代的 K·v 逐元素算(matrix-free)
   ── K 稀疏耦合(B),但從不成形
3. 解出 Δu → 更新節點 DOF → 得各元素應力 σ
4. σ 餵撕裂準則 argmax c → 要撕就 remesh 改拓樸(matrix-free 讓這步免重組)
```
