兩個白內障手術影片資料集:Cataract-1K vs Cataract-LMM

同一個領域(白內障手術影片 AI 分析),兩個各自獨立收案的資料集——不是衍生關係。Cataract-1K(奧地利、單中心、2024)小而全,獨有「術後異常偵測」;Cataract-LMM(德黑蘭、多中心、2026)大規模,獨有「物件追蹤 + 技能評估 + 跨中心 domain shift」。論文原文裡 LMM 把 1K 當比較基準引用。這頁把資料集差異、可正面對照的共通模型、以及各自獨有的演算法整理清楚。

二、可正面對照的共通模型 / 演算法

兩篇都做「階段辨識」與「分割」,所以這兩條線可以 head-to-head。真正 apples-to-apples 的是 CNN + 遞迴層(ResNet-50 骨幹)做階段辨識——兩篇都跑了同一族。

① 階段辨識:CNN + Recurrent(共通基線)兩篇都有

1K:VGG16 / ResNet50 骨幹 + {LSTM, GRU, BiLSTM, BiGRU}。發現:雙向遞迴一致提升 acc/F1;ResNet50 略勝 VGG16。

LMM:同族 CNN+GRU / CNN+LSTM(ResNet-50 與 EfficientNet-B5 骨幹)。CNN+GRU(ResNet-50)≈ 69.7% F1(in-domain)/ 42.8%(out-of-domain)。

→ 同一演算法家族在兩個資料集上都被基準化,是唯一能真正對比「難度/泛化」的公分母。

② 分割:ResNet-50 骨幹同骨幹,不同任務式

1K:語意分割(逐像素分類)。12 種架構,DeepPyramid(VGG16)最佳;含 DeepLabV3+ / UPerNet(ResNet-50)、UNet++、CE-Net、CPFNet…。指標 Dice / IoU。

LMM:實例分割(逐物件遮罩)。YOLOv11-L 73.9 mAP 最佳 > YOLOv8-L 73.8 > SAM 56.0(zero-shot)> Mask R-CNN(R50)53.7。指標 mAP。

→ 共通點是 ResNet-50 骨幹 + Mask R-CNN/DeepLab 家族;但 1K 是語意分割、LMM 是實例分割,指標(Dice vs mAP)不可直接對比。

③ 共通評估慣例:兩篇階段辨識都用 Accuracy / F1;分割則因任務式不同而指標不同(語意=Dice/IoU、實例=mAP)。

核心洞見:互補,不是取代

· 要做「術後異常」(瞳孔反應/IOL 旋轉)、或需要可商用授權 → 用 Cataract-1K(CC BY,獨有 irregularity)。

· 要做撕痕追蹤、技能評估、或驗證跨中心泛化 → 用 Cataract-LMM(多中心,獨有 tracking/skill/OOD)。

· 分割 / 理想圓 → 兩者皆可,但注意 1K 是語意分割、LMM 是實例分割,標註格式與指標不同。

對 SurgeryOCR 的接法:唯一能 head-to-head 的公分母是 CNN+Recurrent(ResNet-50)階段辨識——可先在兩個資料集上各跑一次,量「OCR 螢幕數值訊號」加進去能不能同時提升 in-domain 與跨中心 F1。跨中心那一欄(只有 LMM 有)正好回應 AI meta-analysis 指出的「多為單中心、泛化受限」缺口。
